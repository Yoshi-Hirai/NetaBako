# NetaBako

「投稿したい」と思った瞬間の熱量を、そのまま発信まで運ぶためのツール。

## 概要

NetaBakoは、Web記事や写真を見て「Xに投稿したい」と思ったときに、短い感想を入力するだけでAIが投稿文を作成し、そのまま投稿可能な状態まで進めることを目指す個人開発プロジェクトです。

ニュースを読んで感じたことを後から思い出せなくなったり、ランチの写真を撮ったものの食事を始めて投稿を忘れたりするなど、日常の中で失われている「投稿のきっかけ」を拾うことを目的としています。

## Ver0.1

Ver0.1では、ネタの保存・管理ではなく「その場で投稿する」体験に特化します。

最初に目指す操作フローは以下です。

```text
URLを入力
↓
短い感想を入力
↓
AIがX向けの投稿文を生成
↓
必要に応じて編集
↓
コピーして投稿
```

まずはこの最小構成を実装し、実際に自分で使えるかを確認します。

その後、スマートフォンからのURL共有や写真共有への対応を検討します。

## 開発方針

このプロジェクトの目的は、AIを使った開発そのものではなく、**「誰かに見せられる商品」を完成させること**です。

そのため、最初から多くの機能や複雑な設計を盛り込まず、小さく実装して実際に使いながら改善します。
